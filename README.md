# medium-connect-elements-with-css-part3

Repository used to illustrate [the Medium article](https://medium.com/@rochejul/connect-html-elements-with-only-css-part-3-use-a-bit-of-js-to-be-more-generic-ac4c8c519f87) to illustrate how to connect elements with CSS. This project shows the CSS allowing to adapt the link position/style depending of the box elements positions, but with some JavaScript. Then, we will be able to have more generic approach in the CSS we will produce.

## Live demo

Please use the [live demo](https://rochejul.github.io/medium-connect-elements-with-css-part3/).
